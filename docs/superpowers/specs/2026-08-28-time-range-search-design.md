# 时间范围搜索 `time:` 统一语法(v2 定稿)

> 状态:设计定稿(2026-08-28,v2 吸收五视角评审裁决)
> 关联需求:time-range-search(vault: ~/Obsidian/10-Projects/logview/time-range-search/)

## 背景

现有 `after:HH:MM` / `before:HH:MM` 缺陷:仅时分、忽略日期与秒、跨天语义歧义、多日归档中"每日窗口"错误、语法记忆负担。v1 spec 经 5 视角评审(重度用户/CLI 语法设计/解析器工程/TUI 交互/竞品调研)修订为本版。

## 语法(唯一入口 `time:`;after:/before: 移除)

```
time:>09:00                     今天 09:00 之后(前导零宽容:9:00 ≡ 09:00)
time:>=15:00                    含边界(cron 整点触发行不丢)
time:<10:00:30                  今天 10:00:30 之前
time:>-10m                      相对此刻 10 分钟前
time:-10m                       简写(负号开头默认 >)
time:>-2d / -1h30m              d 单位与复合时长
time:>2026-08-26                完整日期(年必须;MM-DD 无年份格式删除)
time:>2026-08-26T09:00:30       RFC3339 T 连接(_ 为宽容别名,不进文档)
time:10:00..11:00               区间糖(闭区间,含两端)
time:10:00..11:00 OR time:13:00..14:00    多时段
time:>09:00 time:<10:00         区间(显式双条件 AND)
level:ERROR AND time:>-30s      与既有语法正交组合
```

### 移除/禁止

- `after:` / `before:` 前缀移除(输入按未知前缀走现有关键字/字段逻辑)
- **裸 `>X` / `<X`(无 time: 前缀)永不进时间语义**——字面量关键字搜索,防 `<2026-08-26T09:00>` 类日志内容被劫持
- `time:` 前缀后值非法或缺方向符:**显式报错,禁止静默降级**(errorNode,匹配恒 false + hint 红字)

## 解析

- `fieldPrefixes`:`after:`/`before:` 出,`time:` 入
- 值形态按**词法白名单正则**唯一分流(非试探 try-list):
  - `>=?` / `<=?` 方向符 + 时间值;`-数字+单位(s|m|h|d,可复合如 1h30m)` 相对;`值..值` 区间
  - 时间值形态:`H:MM[:SS]`(单位数小时宽容) / `YYYY-MM-DD` / `YYYY-MM-DD[T|_]HH:MM[:SS]`
  - 区间两侧各自按时间值规则,补全规则同单边(时区/年锚定)
- 锚定(全部 **UTC**,与 parser 侧 line.Time 的 time.Parse 无时区语义一致):
  - 纯时分 → anchor 当天 00:00 + 时分;`time.Now().UTC()` 为默认 anchor,**parseSearchQuery 增加 anchor 参数**(测试可注入固定时刻)
  - 相对 → anchor - 时长
- `isPartialQuery` 扩展:输入以 `time:`、`time:>`、`time:>=` 等悬空前缀结尾视为中间态,保持上次结果(消除打字过程结果闪变)

## 匹配

- 全部解析为绝对 `time.Time`,统一比较(`>` `<` `>=` `<=`);区间糖 = `>=下界 AND <=上界`
- `line.Time.IsZero()`(无时间字段行):**任何 time 条件(含 NOT/OR 分支)均不匹配**——NULL 传播,notNode 对 time 型子节点特判
- errorNode:出现在任意子树(含 OR 右支)→ 整个查询匹配空集,但**不 panic 不降级**

## UI

- `TimeRangeHint`:显示**解析后的绝对锚点**(含年/日):`[时间: > 2026-08-26 14:32:05 (-10m)]`、`[时间: 2026-08-26 10:00~11:00]`;解析失败红字 `[time 语法错误:期望 >|<|>=|<=|值..值 + 时间值]`;OR/NOT 语境不显示区间 hint
- **C-t 时间快捷片**(搜索 tab 内,同构 C-r 历史 overlay):最近5分钟/15分钟/1小时/6小时/今天/昨天/自定义占位,Enter 在光标处**追加插入**(AND 流不断),右列渲染规范语法(UI 即教程);"今天/昨天"插入绝对区间形式
- README 搜索语法段重写;帮助弹窗/placeholder 提及 time:

## 测试(锚点注入)

- 匹配:今天锚定跨天(昨天 23:50 不被 time:>09:00 命中)、相对冻结语义、边界含/不含、NOT NULL 传播、errorNode 传播
