# TUI 界面整体优化

## 目标
降低界面信息噪音、统一弹窗交互、提高信息密度：详情栏只显示有效字段、标题栏增加统计与位置、弹窗统一样式、帮助栏拆分为可隐藏的快捷键栏 + 常驻状态栏。

## 约束
- Go + bubbletea/lipgloss，改动限于 internal/tui/
- 不改变现有按键绑定与用户习惯（h/x 仍直达高亮/隐藏，只是入口统一）
- 纯 ASCII 终端可用（现有 Unicode 符号保留，不新增）
- 测试命令：`go test ./internal/tui/`

## 模块拆解
- 详情栏（detail.go）：空字段不再渲染 `field: -` 占位，仅显示非空字段
- 标题栏（app.go）：增加 ERROR/WARN 计数、滚动位置百分比、多文件源时显示源名
- 弹窗统一（searchpopup.go / highlightpopup.go / hidepopup.go / searchbar.go）：搜索/高亮/隐藏统一为同一个 inline 弹窗（复用现有搜索弹窗的三 tab 结构）；h/x 按键改为打开该弹窗并直达对应 tab；删除独立的高亮/隐藏弹窗（代码重复）
- 帮助栏拆分（helpbar.go / app.go）：快捷键提示独立成栏，用 `\` 切换显示/隐藏（默认显示）；状态徽章（过滤/隐藏/搜索/复制反馈）独立为常驻状态栏；隐藏快捷键栏时日志区多 1-2 行
- 帮助弹窗（helppopup.go）：宽终端（≥100 列）双栏布局；高度超出时按分组边界截断并提示
- 级别样式（style.go/theme.go）：ERROR/FATAL 增加深色背景色带

## 关键决策
- 弹窗统一方案选「三 tab inline 弹窗」而非「居中 overlay」：inline 保持日志可见（现有搜索弹窗已解决此问题），且三 tab 结构已存在，删除重复代码约 50 行
- h/x 直达 tab 而非只开搜索 tab：保留单键直达习惯；搜索栏前缀随 tab 显示「搜索:/高亮:/隐藏:」
- 快捷键栏与状态栏分栏而非混排：快捷键是学习成本（可隐藏），状态是运行时反馈（必须常驻，防止误开过滤器无感知）
- 隐藏徽章精简为 `[隐藏:N词]`：完整词列表在隐藏 tab 内可见，状态栏不重复展开
- 标题栏统计用缓冲级计数 map 增量维护，O(1) 每行
- ERROR 背景色带与选中行背景冲突：走 renderLineTextWithBg 既有逐字段铺背景路径

## 风险
- 删除 highlightMode/hideMode 状态涉及按键处理链：相关测试需同步改写（app_test.go 等）
- 快捷键栏隐藏后用户忘掉按键：`?` 帮助弹窗始终可用兜底
- 双栏布局窄边界可能仍超高：按分组边界截断，保底单栏
