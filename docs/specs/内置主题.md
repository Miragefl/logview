# 内置主题

## 目标
内置 11 个开源主题（6 dark：Dracula / Tokyo Storm / Nord / Gruvbox / Catppuccin Mocha / One Dark；5 light：Gruvbox Light / Catppuccin Latte / Nord Light / Tokyo Day / Solarized Light），配置 `theme: <name>` 直接生效。

## 约束
- 配色取自 iTerm2-Color-Schemes（mbadolato）对应 scheme 的官方 16 色 + fg/bg
- 保留现有 dark / light 主题与 theme_colors 覆盖机制不变（向后兼容）
- 主题到 LogView 语义色（level/time/source/accent/popup 等 20 个槽位）的映射遵循各主题官方语义（red→ERROR、yellow→WARN、green→INFO、cyan/blue→accent 类）
- light 主题必须设 Bg/Fg 字段（AppBgSeq 全屏底色），ERROR 色带用浅红底深字（沿用 LevelErrorBg/LevelErrorFg 的亮暗分支）

## 模块拆解
- 主题注册（internal/tui/theme.go）：新增 11 个 ThemeConfig 变量 + builtInThemes map + ThemeNames() 导出列表 + ResolveTheme 支持按名查找
- 颜色映射规则（theme.go 内每个主题）：从 16 色派生 20 个语义槽位（title.bg 用 blue/purple 类主色，popup.bg 用 bg 微暗/微亮色，dim 用 8 号色或 7 号色（light）等）
- 配置文档（cmd/root.go defaultRulesYAML）：theme 注释列出全部可用主题名（dark/light 两行分组展示）
- README：主题章节列表示例

## 关键决策
- 选 iTerm2-Color-Schemes 而非 nvim 插件源：格式统一易提取，且与终端主题一致性最好
- 主题名用小写连字符：dracula / tokyo-storm / nord / gruvbox / catppuccin / one-dark / gruvbox-light / catppuccin-latte / nord-light / tokyo-day / solarized-light
- light 主题每个家族配对引入（gruvbox/gruvbox-light、catppuccin/latte、nord/nord-light、tokyo 两版）+ Solarized Light 补经典：共 5 个，dark 6 个
- 每主题映射写为显式 ThemeConfig 字面量而非程序化转换：可读、可被 theme_colors 精确覆盖

## 风险
- light 主题日志行/弹窗对比度（如 Nord Light 的绿 #A3BE8C 在 #E5E9F0 底上）：light 映射优先用深色变体（非 bright），实现后 tmux 逐主题截图校验
- ERROR 色带在紫底主题上冲突：LevelErrorBg 用主题 red 的深化/亮化变体而非固定色
